# Banking Analytics Dashboard

## Project Overview
Analyzed banking customer data to identify trends in loans, deposits, customer demographics, and account performance. Performed exploratory data analysis using Python and developed interactive dashboards in Power BI to generate business insights.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Power BI

## Key Analysis
- Customer Demographics
- Loan Analysis
- Deposit Analysis
- Income Distribution
- Customer Segmentation
- Banking Product Usage
- Correlation Analysis

## Dashboard Features
- KPI Cards
- Loan & Deposit Analysis
- Customer Banking Insights
- Interactive Filters
- Drill-through Reports
